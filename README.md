# CacheDrop: macOS storage cleaner

A native, local-first macOS app. It finds space you can reclaim on your Mac and cleans what you choose. It was called Still while in development (Decisions 32 and 34); the GitHub repository keeps the name mac-cleaner.

## Install

1. Download `CacheDrop-<version>.dmg` from [GitHub Releases](https://github.com/Patrick-M-Bourget/mac-cleaner/releases).
2. Open it and drag CacheDrop to Applications.

CacheDrop needs macOS 26 or later on a Mac with Apple silicon. It doesn't update itself yet: download a new release to update.
