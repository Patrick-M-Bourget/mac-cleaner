# Optional reason-schema review judgement

The hard review findings (missing caller feedback and coupled reload actions) are being fixed through actual public UI red-to-green journeys. The optional string-vocabulary smell is acknowledged without a schema refactor in this slice. Current version-1 activity JSON uses bounded string-keyed dictionaries, with a fail-closed known-category whitelist, public archive privacy/reload tests, and complete human-readable UI mapping (unknown presentation falls back to a generic explanation). Existing ScanIssue.Reason is not Codable/CaseIterable; changing dictionary keys to a Codable enum would need an intentional wire-format compatibility decision and could widen the current migration. The current finite vocabulary is explicit and tested. This judgement does not exempt future reasons from coordinated validation and presentation changes, or claim that the maintainability smell is absent.
