# Chrome asset-cache qualification and cleanup — locked #18/#19 contract

User confirmed Q1–Q6 October25,2026, then explicitly approved the revised native close-and-clean approach and continued qualification. Revised approval/concurrency rules5–7 below supersede the earlier exact-file/exclusive-lease cache requirement. #19 stays blocked by #18. This contract does not qualify an adapter or enable mutation.

1. **Delivery target:** #18 establishes the capability decision needed for #19's real Chrome cleanup feature. Do not add another standalone guidance screen as a substitute. Preserve the approved Overview → browser/profile review → shared Cleanup plan → permanent confirmation → per-group results journey.
2. **Initial compatibility:** qualify one explicitly verified macOS Chrome Stable release and supported profile layouts. Chrome for Testing156.0.8078.47 evidence remains supporting evidence only, not automatic installed-Stable compatibility. Pin observed tool/version/OS/root provenance. Expand compatibility only with new evidence; unknown versions/layouts remain unavailable for cleanup.
3. **Initial targets:** verified downloaded asset caches only. GPU/code caches and other groups stay unsupported until independently validated and remain retained future scope. Preserve cookies, credentials, history, site/offline storage, autofill, downloads and session/tab state. A familiar path/basename alone never proves ownership.
4. **Access and profiles:** explicitly enable Chrome inspection once; inspect verified profiles under authorized standard storage. Remember access where macOS permits; avoid repeated per-profile pickers. Custom locations require a separate explicit choice. Collect no account addresses or browsing contents. #18 uses disposable native profile roots; personal inspection/discovery UI belongs to qualified #19, not this experiment.
5. **Native close-and-clean approval (revised October25):** approve a specific verified downloaded-asset cache group in a verified Chrome profile, not an immutable manifest of each cache-file inode. Show an observation time and estimated size; refresh/revalidate immediately before execution. Newly generated eligible cache entries within that same approved group may be included by the operation. This exception is only for qualified reproducible Chrome asset caches: never extend it to Downloads, ordinary personal files, another profile, site data or unsupported cache groups. A newly discovered profile/group stays unchecked.
6. **Bounded concurrency protection:** require Chrome and relevant helpers closed; never force-quit or manipulate singleton locks. Revalidate authorized scope, root/ancestor identities, ownership and layout; reject symlinks, changed/replaced directories, protected or unexpected contents and ambiguous access/owner evidence. Observe activity/conflicts before starting and throughout bounded work; stop unstarted work and report partial outcomes if detected. No automatic retry. Process observations/no-follow operations are safeguards, not an external exclusive lease or atomic global snapshot. Accept documented residual reopen/write/final-name-operation races under ordinary use; do not claim protection against adversarial same-user filesystem changes. Inability to obtain a mathematical no-race guarantee alone no longer blocks this model.
7. **Qualification environment and limits:** experiments run only in disposable environments with synthetic browsing data/test credentials, never personal Chrome/profiles/accounts. Qualify an actual Stable artifact, profile/cache ownership, active/reopen/change/denial/swap behavior and protected credential/autofill/history/download/session/offline semantics. Source/probe evidence must state observed detection points, residual races and supported versions/layouts, not promise impossible exclusion. Stop on concrete preservation/scope/provenance failures and report them. Prior exclusive-lease research remains valid for the superseded stronger guarantee; it is no longer a blanket prerequisite for native close-and-clean. No production adapter is enabled by a partial experiment.
